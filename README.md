# CSC320 Module 8 Portfolio Project

**Option #1: Automobile Inventory System**

## Files
- `Automobile.java` — Vehicle class with private attributes, constructors, and required methods (add, list, remove, update) with try-catch handling.
- `AutomobileInventory.java` — Main class that demonstrates all operations including file output.

## Features
- Default & Parameterized Constructor
- Add, Remove, Update vehicle
- List vehicle information (returns String array)
- Save result to text file (`Autos.txt`)
